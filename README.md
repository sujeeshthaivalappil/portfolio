# Sujeesh T V — Portfolio

A clean, responsive personal portfolio for Sujeesh T V, a front-end developer and product implementation engineer. Built with plain HTML, CSS and JavaScript.

## Features

- Single-page portfolio with About, Skills, Experience, Projects, Education and Contact sections
- Responsive mobile navigation and light/dark theme toggle
- Theme preference saved locally and initialized from the system preference
- Active section navigation, scroll reveal effects and back-to-top button
- Accessible contact form with client-side validation (no backend or data submission)
- Reduced-motion support and keyboard-visible focus styles

## Tech stack

- HTML5
- CSS3 (custom properties, Flexbox and Grid)
- Vanilla JavaScript
- Google Fonts (DM Sans and Manrope), with system font fallbacks

## Run locally

Open `index.html` in a browser. No installation, build tools or server are required.

## Deploy with GitHub Pages

Push this repository to GitHub, then open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save. GitHub Pages will publish the site and show its URL in the Pages settings.
